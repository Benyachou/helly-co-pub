# Kit vidéo IA pour la pub Helly-Co (Kling ou Hailuo, crédits gratuits)

Comment s'en servir :
1. Ouvre **klingai.com** (ou **hailuoai.video**), crée un compte gratuit.
2. Choisis « Text to Video » (texte vers vidéo), format **16:9**, durée **5 secondes**.
3. Copie-colle une description ci-dessous (en anglais : ces outils comprennent mieux l'anglais).
4. Si l'outil a une case « negative prompt », colle aussi le texte « À éviter ».
5. Télécharge la vidéo et range-la dans `helyco-pub/videos-ia/` avec le numéro du plan (ex. `01.mp4`).
   Je les trie et je les monte dans le film.

Astuce : Kling accepte aussi une **image de départ** (« Image to Video »). Les images générées
en local dans `C:\Users\zap\ia-locale\serie-helly\` peuvent servir de point de départ :
la vidéo ressemblera alors exactement à l'image choisie.

**À éviter** (à coller dans « negative prompt ») :
```
text, letters, watermark, logo, deformed hands, extra fingers, distorted face, cartoon, cleavage, revealing clothes
```

```
Slow motion cinematic shot: an iPhone slips out of a man's hand and falls onto a stone pavement, the screen shatters on impact, tiny glass shards fly, low angle, shallow depth of field, 35mm film look.
```
